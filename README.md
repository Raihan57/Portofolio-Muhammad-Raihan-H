## 🚀 Cara Menjalankan di Komputer Lokal
Cukup buka file `index.html` langsung menggunakan peramban web (Google Chrome / Microsoft Edge), atau jalankan server lokal:
```bash
# Menggunakan Python
python -m http.server 8000
```
Lalu buka browser di `http://localhost:8000`.

## ☁️ Cara Deploy ke Vercel
1. Upload folder ini ke repositori GitHub Anda (misal `https://github.com/Raihan57/portofolio-raihan`).
2. Masuk ke [Vercel](https://vercel.com), klik **Add New Project**, lalu pilih repositori tersebut.
3. Klik **Deploy** (Pengaturan framework otomatis terdeteksi sebagai static HTML).
